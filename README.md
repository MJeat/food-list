# 🍲 Khmer Food Finder & Decision Spinner

A modern, appetizing, mom-friendly food finder and meal decision spinner built in English for authentic Cambodian (Khmer) dishes like **Somlor** (soups & curries), **Cha** (stir-fries), **Ang & Chien** (grilled & fried), **Nhoam & Pleah** (fresh salads), **Kuyteav** (noodle broths), **Bai** (rice plates), and snacks.

---

## ✨ Features

1. **🎡 Meal Decision Spinner (Home Interface)**
   - Solve *"What should we eat today?"* in one click.
   - Filter specifically for **🌅 Breakfast**, **☀️ Lunch**, **🌙 Dinner**, **🍢 Snack Time**, or **🌟 All Dishes**.
   - Canvas-rendered Wheel of Fortune with rich contrast slices and smooth physics deceleration.
   - Synthesizer Web Audio tick sounds as the wheel turns and celebration fanfare + confetti upon landing.
   - Customizable wheel: check/uncheck dishes or spin only Mom's favorites.

2. **🔍 English Food Search & Library**
   - Search by English name, Khmer phonetics, category, or ingredients (e.g. *pork ribs*, *lemongrass*, *catfish*, *kroeung*, *baguette*).
   - Filter by Khmer Categories:
     - **🍲 Somlor** (Soups & Curries — *Somlor Korko, Somlor Machu Kroeung, Somlor Kari...*)
     - **🍳 Cha** (Stir-Fries — *Cha Kroeung, Cha Lok Lak, Cha Trop Dot...*)
     - **🍢 Ang & Chien** (Grilled & Fried — *Sach Ko Ang, Trey Chien Choun, Moan Ang...*)
     - **🥗 Nhoam & Pleah** (Salads — *Nhoam Svay, Pleah Sach Ko...*)
     - **🍜 Kuyteav & Noodles** (*Kuyteav Phnom Penh, Nom Banh Chok...*)
     - **🍚 Bai & Rice Meals** (*Bai Sach Chrouk, Bobor Sach Moan...*)
     - **🥖 Snacks & Street Bites** (*Num Pang Pate, Num Krok, Kralan...*)
     - **🍮 Bong-Aem / Desserts** (*Bobor Skor Cheik, Num Kroch...*)
   - Interactive recipe cards with interactive ingredients checklist, cooking time, and spice level.

3. **⚙️ Admin Panel**
   - Add new food items with English name, Khmer script, Category, and Meal Times.
   - Quick ingredient tagging and one-click photo presets.
   - Edit, delete, and mark dishes as Mom's Favorites ❤️.
   - Backup & Restore: Export and import JSON data anytime.

4. **👀 Colors & Typography for Mom in her 40s**
   - High-contrast, gentle warm color palette: terracotta clay pot (`#c2410c`), golden turmeric paste (`#d97706`), fresh herb green (`#166534`), soft rice-paper cream background (`#fdfbf7`), and deep charcoal text (`#1c1917`).
   - One-tap **"Text Size: Large (A+)"** toggle in the header for comfortable reading.

## 🚀 How to Run

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build
```
